# 乌兰麦朵 Android 桌面伙伴

面向 Android / 小米澎湃 OS 的桌面陪伴应用开发项目。

## 当前版本

- 版本：0.2.1（持续开发中）
- 原生 Android Kotlin 工程
- 悬浮桌宠：前台服务、可拖动气泡，点击打开聊天页
- 对话页：本机保存最近 100 条聊天消息
- 语音：调用系统中文语音识别入口；使用系统 TTS 朗读回复
- 当前回复引擎：本地基础规则，不是完整大语言模型
- 当前形象：文字悬浮气泡，尚未包含正式 3D 角色模型、骨骼动画或换装

## 构建

GitHub Actions 在 main 分支提交后自动构建 Debug APK，产物名为 `UlanMaDuo-debug-apk`，保留 14 天。

## 安装

下载 Actions 产物中的 `app-debug.apk`，在 Android 设备上安装。首次启动悬浮桌宠时，需要在系统设置中允许“显示在其他应用上层”；启动后可通过通知或悬浮气泡打开聊天页。

## 后续开发

下一阶段将接入可下载的本地语言模型、离线语音组件和正式角色资源。模型和角色资源需要单独下载，避免把数 GB 文件直接塞进 APK。
